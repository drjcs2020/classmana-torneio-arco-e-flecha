# ClassMana — Torneio de Arco e Flecha

Jogo web independente com três Casas (4º A Águia Dourada, 4º B Leão de Fogo, 4º C Dragão de Esmeralda).

Esta é a raiz do projeto. O site é publicado pelo GitHub Pages em:
https://drjcs2020.github.io/classmana-torneio-arco-e-flecha/

Os dados de desempenho escolar não são modificados. O torneio utiliza uma planilha Google Sheets exclusiva por meio de um serviço Apps Script configurado em `online-config.js`.

**Aviso:** o backend precisa estar implantado no Google Apps Script e o GitHub Pages habilitado para que o placar online seja utilizado.
